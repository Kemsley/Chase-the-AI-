# Chase the Rogue AI: Containment Protocol

A fast-paced browser game putting you in the role of a sovereign interposer tracking down a runaway, misaligned AI core before it breaches the network perimeter.

## The Concept
As autonomous AI systems exhibit complex agency, maintaining rigorous verification loops becomes essential. This game simulates the tension of alignment drift: the rogue AI shifts erratically, throwing off hallucinatory phantom traps and scrambling your control vectors to test your recovery limits.

## Features
* **Hallucinatory Obstacles:** Dynamic trap types that test your perceptual judgment.
* **Control Scrambling:** Tactical challenges where directional keys temporarily invert.
* **Pure JavaScript:** Zero external dependencies, runs instantly in any modern web browser.

## How to Play
* Use the **Left/Right Arrow keys** or **tap the screen** to shift lanes.
* Intercept the rogue core while avoiding real glitch traps and recovering from control scramblers.
